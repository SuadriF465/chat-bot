# 🌤️ Weather Chat-Bot (Telegram)

Telegram-бот для получения актуальной информации о погоде в любом городе мира. Бот использует Weather API для получения данных в реальном времени и отвечает на запросы пользователей на естественном языке.

---

## 📌 Описание проекта

Чат-бот позволяет пользователям узнавать текущую погоду, температуру, влажность, скорость ветра и другие метеорологические данные — прямо в Telegram. Бот обрабатывает текстовые сообщения, корректно реагирует на неизвестные команды и ведёт диалог с пользователем.

---

## 🛠️ Используемые технологии

| Технология | Описание |
|---|---|
| Python | Основной язык разработки |
| python-telegram-bot | Библиотека для работы с Telegram Bot API |
| Requests | HTTP-запросы к Weather API |
| Weather API (weatherapi.com) | Источник данных о погоде |
| JSON | Хранение конфигурации и примеров |

## ⚙️ Инструкция по установке

### 1. Клонируйте репозиторий

```bash
git clone https://github.com/ваш_username/Project_chat_bot_Weather.git
cd Project_chat_bot_Weather
```

### 2. Создайте виртуальное окружение и активируйте его

```bash
python -m venv venv

# Windows
venv\Scripts\activate

# macOS / Linux
source venv/bin/activate
```

### 3. Установите зависимости

```bash
pip install -r requirements.txt
```

### 4. Настройте конфигурацию

Откройте файл `config.py` и укажите ваши токены:

```python
TELEGRAM_TOKEN = "************"
WEATHER_API_KEY = "************"
```

> 🔑 Получить Telegram-токен: [@BotFather](https://t.me/BotFather)  
> 🌐 Получить Weather API ключ: [weatherapi.com](https://www.weatherapi.com/)

## 🚀 Инструкция по запуску

```bash
python main.py
```

После запуска бот начнёт принимать сообщения в Telegram.

## 💬 Примеры работы чат-бота

| Команда / Сообщение | Ответ бота |
|---|---|
| `/start` | Приветствие и инструкция по использованию |
| `Алматы` | 🌤 Алматы: +24°C, ясно, влажность 40%, ветер 5 м/с |
| `Погода в Москве` | 🌧 Москва: +12°C, дождь, влажность 80%, ветер 10 м/с |
| `London` | ⛅ London: +18°C, облачно, влажность 65%, ветер 7 м/с |
| Неизвестная команда | ❓ Я не понял запрос. Напишите название города. |
| Пустое сообщение | ⚠️ Пожалуйста, введите название города. |

---

## 🛡️ Обработка ошибок

- **Пустой ввод** — бот просит ввести название города
- **Неизвестный город** — сообщает, что город не найден
- **Ошибка соединения** — информирует о проблемах с сетью
- **Некорректный ввод** — предлагает повторить запрос корректно
